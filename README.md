# Soccer Trail · 球员轨迹 — website

The website for **Soccer Trail**, an Android app that tracks a player in a match video and exports the clip with their running trail.

- Site: https://jerronl.github.io/soccer-trail/
- Privacy policy: https://jerronl.github.io/soccer-trail/privacy.html

This repository holds only the web page; the app's source code is not here.
